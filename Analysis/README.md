# Performance Analysis and Quantitative Characterization

## 1. Overview and Methodology

This directory contains the quantitative performance characterization of all 11 Quantum-dot Cellular Automata (QCA) logic and arithmetic designs synthesized for this project.

### Data Origin and Integrity Protocol:
1. **Measured Layout Metrics (Category B):**
   - **Cell Count:** Extracted by parsing the exact number of `[TYPE:QCADCell]` blocks within each `.qca` file.
   - **Physical Dimensions:** Determined from the bounding box of the cell centers plus standard cell margins:
     $$\text{Width} = (\max(x) - \min(x)) + 18.00\text{ nm}$$
     $$\text{Height} = (\max(y) - \min(y)) + 18.00\text{ nm}$$
   - **Layout Footprint Area:** Calculated directly from the bounding box:
     $$\text{Area} = \frac{\text{Width (nm)} \times \text{Height (nm)}}{10^6}\ \mu\text{m}^2$$
   - **Active Clock Zones:** Set of unique clock indices ($0, 1, 2, 3$) present in the circuit netlist.
   - **Propagation Latency:** Calculated from the clock phase progression:
     $$\text{Latency} = \frac{N_{phases}}{4} \text{ clock cycles}$$
2. **Simulation Status (Category C):**
   - All designs are verified to open cleanly without errors in the native Win32/GTK+ `QCADesigner.exe` (version 2.0.3).
   - In accordance with academic honesty protocols, output waveforms requiring manual GUI visual inspection are categorized as `REQUIRES_MANUAL_QCADESIGNER_VERIFICATION`. No synthetic waveform measurements are claimed.
3. **Literature Benchmarks (Category A):**
   - Comparisons with conventional CMOS nodes (45 nm, 28 nm, 7 nm FinFET) are sourced from published semiconductor literature (ITRS roadmap, Lent et al., Tougaw et al.) and clearly demarcated as theoretical literature benchmarks.

## 3. Visualizations Generated

All charts are generated by `Analysis/plot_performance.py` and saved to `Analysis/plots/`:

1. **`cell_count_by_circuit.png`**:
   - Categorizes circuits into Basic Logic Gates (4 to 7 cells) versus Complex Arithmetic Macro-Circuits (75 to 315 cells).
   - Highlights the progressive complexity growth from single Majority Voters to the 315-cell 4-bit Ripple Carry Adder.
2. **`area_by_circuit.png`**:
   - Contrasts the ultra-compact footprint of primitive gates ($0.003$ to $0.005\ \mu\text{m}^2$) against multi-bit arithmetic units ($0.069$ to $0.292\ \mu\text{m}^2$).
3. **`latency_by_circuit.png`**:
   - Illustrates clock cycle pipelining: basic gates complete within a single clock phase ($0.25$ cycle), single-stage adders/multipliers take $1.00$ cycle, modular addition takes $2.00$ cycles, and the 4-bit ripple carry adder takes $4.00$ cycles.
4. **`area_vs_cells_scaling.png`**:
   - Evaluates the linear correlation between layout area and cell count across all 11 designs:
     $$\text{Area} = 0.902 \times N_{\text{cells}} - 0.008\ \mu\text{m}^2 \quad (R^2 = 0.985)$$
   - Confirms high layout density consistency across both manual and scripted layout synthesis.
5. **`qca_vs_cmos_comparison.png`**:
   - Compares the physical area and static power dissipation of a 1-bit Full Adder across 45 nm CMOS ($8.50\ \mu\text{m}^2$, $45\text{ nW}$), 28 nm CMOS ($3.20\ \mu\text{m}^2$, $18\text{ nW}$), 7 nm FinFET ($0.45\ \mu\text{m}^2$, $6.2\text{ nW}$), and QCA ($0.069\ \mu\text{m}^2$, $< 0.0001\text{ nW}$).
